05 — Usage

Usage Guidelines

The mark and wordmark carry institutional weight. Handle them with the same precision we bring to the infrastructure itself.

Do
  • Use the white mark on dark backgrounds as the default
  • Maintain the prescribed clear space on all sides
  • Use the mark at the supplied aspect ratio — never stretch or skew
  • Use "InfraSingularity" as one camelCase word in all copy
  • Apply Outfit for all headings and display text
  • Apply Figtree for body text and UI elements
  • Use #6B4FEC as the sole brand accent — don't substitute
  • Use dark backgrounds (#0A0D10) as the primary environment
Don't
  • Don't place the mark on busy or photographic backgrounds
  • Don't use the mark below 16px at any size
  • Don't add drop shadows, gradients, or effects to the mark
  • Don't recolour individual dots or alter the mark geometry
  • Don't write "Infra Singularity", "infrasingularity", or "IS" in formal contexts
  • Don't use more than two brand accent colours in a single layout region
  • Don't use rounded corners — the brand is sharp and geometric
  • Don't approximate — always use supplied SVG files
